# Самир – сайт-портфолио (монтаж Reels и подкастов)

Светлый стеклянный дизайн с серебряными шахматами, сетка из 4 вертикальных Reels (наведение → ролик оживает,
клик → открывается со звуком), раскрывающийся блок подкаста, FAQ и контакты.

Стек: **React + Vite + Tailwind + Framer Motion**. Шрифты лежат внутри проекта (Onest + Playfair Display),
внешних запросов нет – сайт одинаково открывается через VPN и на медленном интернете.
Деплой: **GitHub → Netlify** (автоматически).

```
samir-portfolio/

├── public/
│   ├── videos/

│   │   └── blog-avatar.mp4           ← видео-аватар telegram-блога (квадрат 1000×1000)
│   ├── img/
│   │   ├── avatar.jpg    ← твоё фото (вертикальное 3:4) – просто замени файл
│   │   └── blog.jpg      ← картинка-заглушка аватара блога (показывается, пока грузится видео)

└── netlify.toml          ← настройки Netlify (уже готовы)
```

## 2. Как заменить видео (самый частый случай)

Проще всего – **заменить файл с тем же именем**: положи свой ролик в `public/videos/` как `reel-1.mp4`
(вместо заглушки) – и больше ничего делать не нужно. То же с `reel-2…4`, `podcast.mp4`, `blog-avatar.mp4`.

Если хочешь другое имя файла – положи файл в `public/videos/` и поправь путь в `src/content.js`:

```js
export const reels = [
  { src: '/videos/reel-1.mp4', poster: '' },   // poster можно оставить пустым
  { src: '/videos/reel-2.mp4', poster: '' },
  { src: '/videos/reel-3.mp4', poster: '' },
  { src: '/videos/reel-4.mp4', poster: '' },
]
```

> Сетка рассчитана ровно на 4 ролика (по 4 в ряд на компьютере, по 2 на телефоне).
> Можно добавить 8 – будет два ряда. Подкаст прописан отдельно: `podcast.video`, аватар блога – `site.blog.video`.

### Как экспортировать, чтобы грузилось быстро (важно для телефонов и VPN)

| Что | Параметры | Размер |
|---|---|---|
| Reels | 1080×1920, H.264 (mp4), **6–8 Mbps**, 30 fps, звук AAC 128 kbps | 10–20 МБ |
| Подкаст | фрагмент 1–3 минуты, 1920×1080, H.264, 6–8 Mbps | до ~50 МБ |
| Аватар блога | 1000×1000 (можно 600×600), 3–6 секунд, без звука | до 5 МБ |

- Premiere / CapCut: пресет «Match Source – High bitrate» → поменяй битрейт на 6–8 Mbps.
- Если файл тяжёлый – пережми в **HandBrake** (бесплатно): пресет «Fast 1080p30», качество RF 24–26,
  в «Web optimized» поставь галочку (чтобы видео начинало играть до полной загрузки).
- Через командную строку: `ffmpeg -i in.mp4 -c:v libx264 -crf 24 -preset slow -movflags +faststart -c:a aac -b:a 128k out.mp4`

**Лимиты GitHub:** через браузер – файл до **25 МБ**, через GitHub Desktop / git – до **100 МБ**.

## 3. Как заменить фото, аватар блога и тексты

- **Своё фото** → замени `public/img/avatar.jpg` (имя файла оставь тем же).
- **Видео-аватар блога** → замени `public/videos/blog-avatar.mp4`; картинку `public/img/blog.jpg` тоже
  замени на кадр из него (она видна, пока видео грузится, и там, где автоплей запрещён).
- **Тексты, цифры, FAQ, ссылки** → `src/content.js`. Там всё подписано комментариями.
- **Зелёный огонёк «available for work»** → `site.available: true / false`.
- **Цвета** → `src/index.css`, блок `:root` в самом верху (`--accent` – синий акцент).

## 4. Деплой: GitHub → Netlify (без терминала)

### Первый раз

1. **GitHub**: создай аккаунт → `New repository` → имя `samir-portfolio` → `Create`.
2. На странице репозитория: `Add file → Upload files` → перетащи **всё содержимое** папки проекта
   (кроме `node_modules` и `dist`, если они есть) → `Commit changes`.
   Удобнее через приложение **GitHub Desktop**: `Add → Add existing repository` → `Publish`.
3. **Netlify** (netlify.com): войди через GitHub → `Add new site → Import an existing project → GitHub`
   → выбери `samir-portfolio` → настройки подхватятся из `netlify.toml`
   (Build command `npm run build`, Publish `dist`) → `Deploy`.
4. Через 1–2 минуты сайт доступен по адресу вида `https://что-то.netlify.app`.
   Своё имя: `Site configuration → Change site name` или подключи домен в `Domain management`.

### Обновления

Заменил/добавил файл в репозитории (на GitHub `Upload files` с тем же именем = замена)
→ Netlify автоматически пересобирает сайт. Больше ничего делать не нужно.

## 6. Как устроены карточки видео

- В покое превью чуть приглушено; при наведении – ярче, крупнее, ролик играет без звука.
- Клик → модальное окно со звуком: вертикальное для Reels, горизонтальное для подкаста.
  Стрелки ← → листают ролики, `Esc` закрывает.
- На телефонах (нет наведения) ролик запускается, когда карточка в зоне видимости, и ставится
  на паузу, когда уходит с экрана, – поэтому телефон не греется и не лагает.
- Видео подгружаются только метаданными (`preload="metadata"`), пока их не навели/не открыли.
